## 👨‍💻 Sobre mim / About me

Sou um desenvolvedor apaixonado por tecnologia e arquitetura de software, focado em construir soluções robustas de ponta a ponta. Tenho forte atuação no ecossistema corporativo, focado no desenvolvimento de APIs de alta performance, integrações complexas de sistemas e interfaces modernas (web e mobile).

Meu objetivo é resolver problemas complexos através de código limpo e manutenível. Tenho experiência prática aplicando **SOLID**, **Clean Architecture** e projetando otimizações avançadas em bancos de dados relacionais para extração eficiente de dados.
